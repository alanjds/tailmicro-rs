Control-key pin signer

Does in the browser what tools/gen_fingerprint.py does: fetches the control server key over validated HTTPS and signs a 109-byte pin with your Ed25519 seed. Everything runs locally. The seed is never sent anywhere.

This browser has no WebCrypto Ed25519 (needs Chrome 137+, Firefox 129+ or Safari 17+). Update the browser, or run python3 tools/gen_fingerprint.py instead.

1. Signing seed

New seed generated and kept in memory. Save the downloaded tm_signing_key.bin somewhere safe, it is the only copy. Paste this verify key into PIN_VERIFY_KEY in the firmware:


      
Changing the verify key needs a firmware rebuild. Devices built with the old key reject pins signed by the new seed.
